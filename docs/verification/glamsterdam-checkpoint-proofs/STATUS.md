# Progressive checkpoint proof qualification in progress

The real mainnet-preset Gloas process serves a current attested bootstrap but returns 404 for its latest finalized checkpoint, whose actual block is before a skipped epoch-boundary slot. Complete header roots match independent SHA-256 Merkle reconstruction. Production pruning now consumes a sorted/deduplicated list of actual canonical block slots; the older proof-pruning helper assumes per-state slot roots, which repeated the previous block root at skipped epoch boundaries. That semantic mismatch can delete the required current-sync-committee proof. This review reproduces and corrects the pruning decision before qualifying real progressive proof consumers; it does not reinterpret a missing marker/comment as missing proof support.
