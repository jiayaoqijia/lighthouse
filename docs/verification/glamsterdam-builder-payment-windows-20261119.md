Test source 39168a37d adds three release controls with an explicit Minimal Gloas harness and actual real-BLS signed external builder bid. The bid is validated by process_execution_payload_bid with signature verification enabled; recording reserves its amount without debiting the builder. The selected authority is consensus-specs 2ea9d96a, including settle_builder_payment, deferred parent application, quorum-window rotation, proposer-slashing cancellation and expected withdrawals.

The window driver covers current, previous and evicted/no-quorum late parents. A settled slot clears, and a second settlement leaves the entire state root unchanged. Actual process_withdrawals exposes one flagged builder withdrawal with the expected fee recipient and amount, debits that same amount from the builder and removes the queue entry. A following withdrawal phase cannot pay it again. Exit is blocked before payment and permitted after its pending balance clears. The invariant is builder balance plus its actual emitted withdrawal equals its original balance.

Quorum controls pin below/equal/above threshold outcomes, exact ordered queued recipients, current-to-previous movement and no-quorum eviction without a debit. The actual slash_validator path cancels the recorded proposer's pending payment; subsequent parent application and withdrawal processing do not pay that proposer or debit the builder. Validator slashing penalties and rewards are separate legitimate supply effects, not silently counted as builder payment.
