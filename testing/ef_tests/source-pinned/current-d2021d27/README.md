# Complete current Gloas full-node reference

Source: consensus-specs `d2021d2719235f0df4726a1d330502cb15aa8ea3`
(1.7.0-beta.5 source, not the older published beta.4 fixture release).
The unchanged Git source archive is shared with the adjacent `fcr-d2021d27`
bundle and includes its upstream license. The dynamic archive retains 2,525
independently generated cases and 23,920 byte-hashed files. XZ compression
preserves the same files as the original generated SSZ/Snappy inputs.

`current_reference.py` verifies every archived file, independently regenerates
all 9,344 SSZ cases from that source, and verifies every regenerated byte against
`ssz.manifest.json.gz` before native SSZ round-trip/root checks. The 330 FCR
cases are supplied by `fcr-d2021d27`: 196 Gloas cases and 134 affected historical
compatibility cases. Expected objects never come from the client under test.

Acceptance requires 12,195 native case receipts: 2,515 dynamic cases in the real
BLS profile, six operation fixtures explicitly declaring `bls_setting: 2`, 330
FCR fixtures with synthetic signatures and real public-key aggregation, and
9,344 SSZ cases. Synthetic profiles are not real-BLS evidence. Missing cases,
unknown consumers, load failures, duplicate receipts and skipped/waived cases
fail qualification. The four retained `light_client/sync` vectors describe a
light-client **client/store** role, not this full-node server; the inventory
explicitly reports them as unrun and excludes them from the passed count.

Run from a clean committed checkout. Use new absolute output directories outside
the repository, preserving previous evidence:

```sh
python testing/ef_tests/current_reference.py prepare /tmp/current-inputs
python -m pip install '/tmp/current-inputs/reference[test]'
(cd /tmp/current-inputs/reference && python -m pysetup.generate_specs --all-forks)
python testing/ef_tests/current_reference.py regenerate-ssz /tmp/current-inputs
python testing/ef_tests/current_reference.py build /tmp/current-binaries
python testing/ef_tests/current_reference.py run /tmp/current-inputs /tmp/current-binaries /tmp/current-results
```

Use Python 3.12–3.14 with upstream's exact dependencies and the repository's Rust
toolchain. The complete current-reference CI workflow runs the same commands.
Every native case records the compiled clean source revision and crypto mode;
immutable executable copies have digest receipts and are checked before replay.
This qualification does not claim 48-hour or larger-scale acceptance, Lodestar
upstream approval, a full Ethereum STF guest, or resolution of original-04.
